# Vegupathirajan Gothandaraman - Developer Portfolio

A responsive developer portfolio website designed to showcase backend engineering capabilities, AI voice agent architecture, and featured client projects.

## 🚀 Free Hosting & Deployment Options

### Option 1: GitHub Pages (Recommended - 100% Free)
1. Push this folder to a GitHub repository named `vegudev.github.io` (or `portfolio`).
2. Go to repository **Settings** -> **Pages**.
3. Under **Branch**, select `main` and root `/` folder, then click **Save**.
4. Your site will instantly be live at: `https://vegudev.github.io`

### Option 2: Vercel or Netlify (1-Click Deployment)
1. Go to [vercel.com](https://vercel.com) or [netlify.com](https://netlify.com).
2. Connect your GitHub account and pick this repository.
3. Click **Deploy**.

## 🛠 Local Preview
Simply double click `index.html` in your file explorer, or run:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.
