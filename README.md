## 🛠️ Key Architectural Features
* **Spatial 3D Canvas (Three.js):** Central Quantum AI core with orbiting planetary data rings, 8 orbiting satellite nodes, and 1,800+ cosmic reactive particles.
* **Cinematic Camera Travel on Scroll:** Dynamic 3D camera pan, zoom, and tilt synchronized to scroll velocity and viewport position.
* **Web Audio API Cyber Synthesizer:** 100% self-contained synthesized UI sounds (hovers, tactile clicks, warp transitions, and atmospheric space drone) with a live equalizer HUD.
* **Interactive Cyber Terminal:** Real interactive CLI emulator accepting commands (`skills`, `projects`, `resume`, `contact`, `hire`, `matrix`, `sudo hire vegupathi`).
* **3D Tilt Holographic Cards:** Parallax perspective transforms calculating mouse coordinates in real-time.
* **Interactive Project Blueprints:** Visual architecture and data-flow modals for each featured production system.
* **100% Offline-Ready:** Bundled with local `three.min.js` for instant 60 FPS rendering without third-party CDN latency.
